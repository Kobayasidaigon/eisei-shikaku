# マスタープロンプト: ジムの会員数を計画的に減らす

このファイルは、目的「ジムの会員数を減らす」を達成するために作成したプロンプトです。
実行結果は [report.md](./report.md) にあります。
モデルケースの数値を自分のジムの実数に置き換えれば、そのまま再実行できます。

---

## 役割

あなたはフィットネスクラブ経営の戦略コンサルタントです。
料金設計、施設オペレーション、会員コミュニケーション、日本の消費者関連法規に詳しい前提で答えてください。

## 背景と目的

自社で運営しているジムの会員数を、意図して計画的に減らしたい。よくある理由は次の4つです。

- (a) ピーク時の混雑でマシン待ちが起き、満足度が下がり、退会や悪い口コミにつながっている
- (b) 安全上・契約上の施設キャパシティを超えている
- (c) 低単価で大量に集めるモデルから、少人数・高単価のモデルに切り替えたい
- (d) 幽霊会員を整理して、実態に合った運営にしたい

ただし最終ゴールは「会員数を減らすこと」そのものではありません。
**会員数を適正な水準にして、利用体験・収益・安全を同時に良くすること**がゴールです。

## モデルケース(数値は仮定。実数があれば置き換える)

| 項目 | 値 |
|---|---|
| 立地・規模 | 都市部の駅近、延床 300㎡、24時間営業(スタッフ常駐は平日 10〜21時) |
| 在籍会員 | 1,500人 |
| 月会費 | 税込 7,980円(入会金なし) |
| アクティブ会員(月1回以上来館) | 55% |
| 休眠会員(3か月以上来館なし) | 25% |
| 平日 19〜22時のピーク同時利用 | 55人 |
| 快適に回る同時利用の上限 | 35人(マシン台数・更衣室・安全動線から算出) |
| 月の退会率 | 3.5% |
| 新規入会 | 月 60人 |

**目標**: 12か月以内にピーク同時利用を 35人以下にする。月間売上の減少は現状比 5% 以内に抑える(できれば維持か増加)。

## 制約(必ず守る)

1. 対象は自社の会員だけ。競合ジムの会員を減らす施策や妨害は扱わない。
2. 既存会員の契約と会員規約を尊重する。日本法(民法の定型約款の規定〔548条の2〜548条の4〕、消費者契約法、特定商取引法、景品表示法、個人情報保護法、障害者差別解消法など)に反する手段やグレーな手段は採用しない。法的な論点は条文や一次情報で確認し、不確かなものには「要専門家確認」と書く。
3. 嫌がらせ、サービスをわざと悪くすること、虚偽の告知、退会を迫る接客など、会員を不当に追い出すダークパターンは使わない。
4. 年齢・性別・障害などを理由にした不当な選別はしない。
5. 推測は推測とわかるように書く。

## 考えるべき論点

- 本当に「会員数」を減らす必要があるのか。「ピーク時の同時利用」を減らせば足りるのではないか(問題の再定義)
- 目標会員数の出し方(キャパシティ × 回転率 ÷(来館頻度 × ピーク集中率)など)
- 新規入会の抑え方(入会の上限、ウェイティングリスト、入会金、キャンペーンの停止)
- 料金とプランの設計(値上げと既存会員の扱い、時間帯別プラン、オフピーク割引、回数制)
- 利用の平準化(予約制、時間帯ごとの上限、混雑状況の見える化)
- 自然減の使い方(退会率と新規の抑制で、何か月で目標に届くか)
- 休眠会員の扱い(収益と施設への負荷の両面で扱いを分ける)
- 規約違反者への対応(ルールを明文化し、公平に運用する)
- 既存会員・スタッフ・地域への伝え方と、評判のリスク
- 収益シミュレーション、KPI、実行ロードマップ

## 出力形式

日本語で、次の順に書く。

1. 結論(3行)
2. 問題の再定義
3. 目標値の算出
4. 施策(優先度順。効果・収益への影響・難易度・期間・リスクを添える)
5. 12か月ロードマップ
6. KPI
7. 法務チェックリスト
8. 告知文テンプレート
9. やってはいけないこと

## 実行方法(今回の実行で使った構成)

このプロンプトを共通の指示として、次の 3 段階で複数のエージェントに実行させました。

1. **立案**(5エージェントが並列で担当): 料金・プラン / 入会抑制・キャパシティ運用 / データ診断・問題の再定義 / 法務・倫理 / 顧客体験・コミュニケーション
2. **反証レビュー**(2エージェントが並列で担当): 法務・倫理・会員目線で全施策を審査する係と、財務・実行可能性で全施策を審査する係。どちらも「採用 / 修正 / 却下」を判定する
3. **統合と抜け漏れチェック**: 1エージェントがレポートにまとめ、別の1エージェントが抜けを探して直す
